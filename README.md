# Marielle Modesto Portfolio

This portfolio is built with vanilla HTML, CSS, and JavaScript for GitHub Pages deployment.

## Run locally
- Open the file directly in a browser: `Portfolio/index.html`
- Or serve the project with a simple static server from the root folder

## Deployment
- Push the repo to GitHub
- Enable GitHub Pages
- Use the root or the `Portfolio` folder as the Pages source, depending on your repo settings

No Flask server is required for this project.
